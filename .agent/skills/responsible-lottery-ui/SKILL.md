# Responsible lottery UI

## Required (every page footer + generator + Bao calculator)
"Kết quả xổ số là ngẫu nhiên. Thống kê quá khứ không giúp dự đoán kỳ quay sau. Trang này chỉ mang tính tham khảo và giải trí, không liên kết với Vietlott. Chỉ dành cho người từ 18 tuổi trở lên. Hãy chơi có trách nhiệm."

## Required features
- 18+ confirmation gate (remember choice locally; no tracking).
- Every generated set shows its true probability (identical for all sets of the same game).
- Bao calculator shows ticket count, total cost, jackpot probability, and expected value (usually negative).
- A "Kiến thức" page explaining independence, gambler's fallacy, and odds.

## Forbidden wording
"dự đoán chính xác", "chắc trúng", "số đẹp bảo đảm", "tăng tỷ lệ trúng" (for a single ticket), "số sắp ra", "mua ngay", urgency/countdown pressure, flashing jackpot animations, win-celebration visuals, links to buy tickets, affiliate links.
Preferred: "bộ số tham khảo", "thống kê lịch sử", "tần suất trong quá khứ".

## Design
Calm, neutral, accessible (WCAG AA), mobile-first, Vietnamese typography verified with diacritics. Use the `frontend-design` skill for visual quality only; it must not override the rules above.

## Legal
Add a note in docs that the owner should consult a Vietnamese lawyer about publishing lottery-related content. Do not give legal conclusions.
